This very website you are on is technically one of my projects as well. Not that I've really *learnt* much from it, but it's definitely fun and a good way of killing time when I'm bored.

If you happen to be interested, the source is available at [this GitHub repo](https://github.com/silas-hw/silas-hw.github.io). I do warn you, the last thing I am is a web developer, so the html and css here may not be the best (although I don't really have the capability of objectively analysing css or html in all honesty, I do what works and thats it!).

I happen to be taking a module in HCI next year, which is supposedly almost exclusively UX work. You may, if you are for some reason stalking me and checking this website regularly, see what I learn come into action (or you may not, it depends how much I actually work on this site).

I have always had an admiration for 2000s era website. The sort made with GeoCities. Whilst this isn't made with some alternative like NeoCities, I still somewhat take inspiration. I don't really want overly convoluted transitions and styling. I want janky! I want tiled backgrounds! I want weird fonts! Whilst I might not perfectly capture that, I'm still going to have some fun :3
